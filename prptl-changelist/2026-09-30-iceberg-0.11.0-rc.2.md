# 2026-09-30 Iceberg 0.11.0 RC2 Rebase

## Baseline

- Apache release tag: `v0.11.0-rc.2` (`859048563`).
- Fork source: `perpetual-main` / `perpetual-v18`
  (`50c009af77d247cb9dc9983b7a654d659ca05be1`).
- Previous imported Apache baseline: `6077a42ea061f73a561c26880993f84fafb1ba0f`.
- Working branch: `aaron/rebase-v0.11.0-rc.2`.

The fork's net extensions were replayed as a consolidated patch onto the release
tag. Replaying historical commits would also replay earlier squashed upstream
imports. The original `perpetual-main` branch is preserved.

RC2 still contains `iceberg-datafusion`, so the bundled integration and its tests
remain. The later extraction on Apache main is outside this update. This baseline
uses DataFusion 54 (54.1.0 in the lockfile), Arrow/Parquet 58.4, and Rust 1.95.

## Retained Extensions

- Maintenance transactions: merge append, rewrite files, rewrite manifests,
  row delta, delete files, manifest filtering/merging, and retry identifiers.
- Bounded incremental scans and manifest-derived scan statistics, split offsets,
  and sort order IDs.
- Caller-supplied Arrow schemas for core readers/writers, row-group flushing,
  data-file sort order stamping, and partition/projector name matching.
- Public DataFusion physical plans and table-provider construction, scan schema
  propagation, and timezone-aware timestamp predicates.

These remain required by the fork's consumers or supporting maintenance APIs;
RC2 does not replace them.

## Retired and Adapted Code

- Removed the unusable per-action `set_key_metadata` APIs. Maintenance operations
  now use upstream's table encryption manager for manifests and manifest lists,
  including residual and merged manifests. A regression test covers encrypted
  rewrites with manifest merging both enabled and disabled.
- Replaced the fork's generic property parser with RC2's typed table-property
  getters for manifest merge configuration.
- Replaced direct manifest loading with upstream manifest readers, and hardcoded
  metadata directories with the table's configured metadata location.
- Kept upstream's concurrent duplicate-file validation, Parquet writer property
  handling, encryption, CDC options, row lineage, and virtual metadata columns.
- Removed the DataFusion writer's legacy Arrow-schema override: its output schema
  describes serialized data-file results, not the input rows. The upstream writer
  path passes the existing partitioned and unpartitioned writer tests.
- Updated fork scan metadata to RC2's `FileScanTask` builder while preserving its
  new upstream fields. Updated public API snapshots for the retained extensions.

## Compatibility Notes

Downstream projects have not been migrated or built as part of this update.
RC2 introduces upstream API changes, including encapsulated `FileScanTask`
fields/accessors, that callers must adopt when updating their dependency.
