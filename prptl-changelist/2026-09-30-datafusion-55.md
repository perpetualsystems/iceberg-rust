# 2026-09-30 DataFusion 55 Upgrade

## Assessment

The Rust migration is small: dependency alignment plus six Rust source files,
with no core Iceberg Rust source changes. This candidate is based on the RC2
rebase commit `6148e90e0` and lives on `aaron/datafusion-55`.

The lockfile resolves DataFusion 55.1.0 and Arrow/Parquet 59.3.0. All direct
DataFusion workspace dependencies move to major 55, and Arrow/Parquet to 59.2
or newer within major 59. A single Arrow version is shared by core Iceberg,
the integration, and DataFusion. The Rust requirement stays at 1.95.

## Source Changes

- Implement the newly required `ExecutionPlan::apply_expressions` on four
  Iceberg execution plans and two test plans. These nodes hold no DataFusion
  physical expressions; Iceberg scan predicates are already converted to
  Iceberg predicates.
- Import `TableReference` from `datafusion::common`.
- Adapt external-table creation to `CreateExternalTable::locations`. An Iceberg
  static table still requires exactly one metadata location; reject empty or
  multiple locations explicitly, with regression coverage.
- Enable `serde_arrow`'s `arrow-59` feature for core tests.
- Align the workspace's PyO3 dependency to 0.29 because Arrow 59's PyArrow
  feature requires it. Update the capsule constructor so the Python member's
  Rust code continues to compile. Python runtime/package support is outside
  this task's scope and was not validated.

## Validation

- Core unit tests, all features: 1,779 passed.
- DataFusion unit tests, all features: 92 passed.
- Workspace Clippy, all targets and all features, warnings denied: passed.
- Formatting and whitespace checks: passed.
- Core public API snapshot is unchanged.
- DataFusion doctests: 1 passed, 5 ignored by the existing suite.
- DataFusion API snapshot regenerated; changes are the required expression
  visitor methods and upstream table-provider traits moving to `datafusion_session`.

Docker-backed integration tests were not rerun: the RC2 validation attempt
was blocked by HTTP 401 pulling the pinned MinIO image from Quay.

## Adoption

Simba currently declares DataFusion 54.1 and Arrow 58. It must upgrade those
dependencies together with the fork; Arrow 58 and 59 Rust types cannot be
interchanged. No downstream consumer code was changed or built in this task.
This assessment establishes the size and validation of the iceberg-rust change,
not the size of the downstream Simba migration.

References:

- [DataFusion 55 dependency requirements](https://github.com/apache/datafusion/blob/55.0.0/Cargo.toml)

The actual 55.1.0 crate sources and compiler diagnostics determined the required
edits; the live upgrade guide also lists changes not present in those crates
(for example, their scan projection signatures still use `Option<&Vec<usize>>`).
